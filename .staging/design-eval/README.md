# 디자인 스킬 공통 실사용 과제

## Why

같은 입력을 다른 디자인 스킬에 넣고 실제 결과를 비교해, design-conductor가 결과물 종류에 따라 맞는 스킬을 고르게 한다.

## 공통 제품

- 이름: Rottie
- 정체: 터미널, 파일 탐색기, 텍스트 편집기, 명령 팔레트, 기본 AI 패널을 한 창에서 잇는 Tauri 데스크톱 AI 작업 IDE
- 핵심 사용자: 매일 코드를 고치고 명령을 실행하는 개발자
- 해결할 불편: 파일, 터미널, AI 대화를 여러 앱에서 오가느라 작업 흐름이 끊긴다.
- 약속: "코드와 명령과 AI가 한 작업 흐름으로 이어진다."

## 공통 과제 A: 랜딩 히어로

- 1440x900 데스크톱과 390x844 모바일에서 한 화면 안에 들어오는 히어로 1개
- 실제 문구:
  - eyebrow: `ROTTIE / DESKTOP AI IDE`
  - 제목: `생각이 끊기기 전에, 코드까지.`
  - 설명: `파일을 찾고, 명령을 실행하고, AI와 고친다. 흩어진 개발 작업을 한 창에 잇습니다.`
  - 주 버튼: `Rottie 시작하기`
  - 보조 버튼: `작업 흐름 보기`
- 가짜 고객 수, 가짜 성능 수치, 가짜 추천 문구 금지
- 외부 이미지와 CDN 없이 로컬 HTML/CSS/JS만 사용
- 결과: `hero/index.html`

## 공통 과제 B: 다크 관제 카드

- 기존 판 관제 대시보드의 Terminal 테마를 참고한 카드 1개
- 기존 토큰:
  - 바닥 `oklch(14% 0.012 160)`
  - 카드 `oklch(19% 0.016 160)`
  - 카드 안쪽 `oklch(23% 0.018 160)`
  - 글자 `oklch(88% 0.02 150)`
  - 흐린 글자 `oklch(64% 0.02 150)`
  - 인광 초록 `oklch(80% 0.17 150)`
  - 경고 주황 `oklch(80% 0.13 85)`
  - 오류 빨강 `oklch(72% 0.15 25)`
  - 보조 청록 `oklch(78% 0.10 220)`
  - 모노 글꼴, 4px 간격 체계, 4px 모서리
- 카드 내용:
  - 제목 `RUN / design-skill-eval`
  - 상태 `3 / 5 active`
  - 작업자 `frontend-design`, `canvas-design`, `web-design-reviewer`
  - 최근 신호 `검수 대기 2`, `경고 1`, `완료 7`
- 900x700과 390x844에서 잘림·가로 넘침 없음
- 결과: `dashboard-card/index.html`

## 공통 과제 C: 주특기

- 각 SKILL.md가 가장 잘한다고 주장하는 작업을 그대로 선택한다.
- 결과 디렉터리: `specialty/`
- 어떤 주장을 시험했는지 `specialty/README.md` 최상단에 적는다.

## 검수 계약

- 각 HTML은 단독으로 열려야 한다.
- 키보드 포커스가 보여야 한다.
- `prefers-reduced-motion`을 존중한다.
- 결과물마다 `evidence.md`에 사용한 SKILL.md 경로, 따른 핵심 규칙, 일부러 쓰지 않은 다른 스킬을 기록한다.
- 외부 네트워크, 비밀값, 사용자 계정, 외부 API를 사용하지 않는다.

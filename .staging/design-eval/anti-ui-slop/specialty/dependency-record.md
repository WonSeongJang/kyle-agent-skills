# 외부 레퍼런스 의존성 실측

## 시도 조건

- 스킬 원문은 `https://ui.zef.dev/...` 카탈로그에서 실제 사이트를 골라 브라우저로 열도록 요구한다.
- 이번 설치 안전 계약은 평가 산출물 제작 중 외부 네트워크와 데이터 전송을 금지했다.

## 결과

- 외부 카탈로그 없이 남는 것은 anti-pattern 목록과 "실재 디자인을 비교하라"는 절차다.
- anti-pattern 목록은 보통 수준으로 유용하지만 기존 `hallmark`, `web-design-guidelines`, `frontend-design`과 중복된다.
- 핵심인 실재 사이트 비교를 빼면 독립 스킬로 편성할 이유가 약하다.

## 운용 제안

- 인터넷 탐색이 허용된 랜딩 리디자인 전 조사에만 전문 보조로 부른다.
- 비공개 앱, 오프라인 환경, 빠른 코드 검수에는 부르지 않는다.

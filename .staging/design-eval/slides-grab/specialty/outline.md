# Rottie 3슬라이드 출시 덱

## Why

흩어진 개발 도구 사이를 오갈 때 끊기는 생각을, Rottie가 한 창의 흐름으로 잇는다는 점을 3장 안에 설명한다.

## 승인된 평가 개요

1. 문제 — 코드는 에디터에, 명령은 터미널에, 질문은 다른 AI 창에 있다.
2. 해결 — 파일 → 터미널 → AI → 저장이 같은 문맥에서 이어진다.
3. 약속 — 생각이 끊기기 전에 코드까지.

## 시각 방향

- 16:9, 깊은 녹색 Terminal 톤.
- 한 장 한 메시지, 큰 한국어 제목, 모노 보조 정보.
- 외부 이미지 없이 CSS 선과 카드만 사용.

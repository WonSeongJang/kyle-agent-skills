# 다크 관제 카드 감사

## 대상

- `.staging/design-eval/frontend-design/dashboard-card/index.html`
- 화면: 900x700, 390x844

## 발견

| 심각도 | 문제 | 근거 | 제안 |
|---|---|---|---|
| Major | 대문자 영문 banner가 한국어 관제 문맥보다 먼저 읽혀 정보 우선순위가 뒤집힌다 | 가장 밝은 초록 면적이 전체 폭을 차지 | 초록은 3/5 상태에만 제한하고 RUN 경로는 흐린 글자로 이동 |
| Minor | 작업자 카드 높이 130px는 정보량보다 크다 | 이름+역할 두 줄뿐 | 88~96px로 축소 |
| Minor | 모바일에서는 카드가 길지만 가로 넘침은 없다 | 390px CSS 재배치 확인 | 유지 가능 |
| Note | 기존 Terminal 토큰과 3개 의미 색을 정확히 보존한다 | OKLCH 값 일치 | 유지 |

## 판정

조건부 통과. 시각적 개성은 강하지만 관제에서는 장르보다 신호 우선순위가 중요하다.

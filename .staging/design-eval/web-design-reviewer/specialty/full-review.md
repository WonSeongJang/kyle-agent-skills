# 전체 검수 체크리스트 실사용

## Why

Web Design Reviewer가 단순 미감 평이 아니라 실제 화면 크기, 위계, 반응형, 접근성, 구현 일관성까지 한 번에 잡는지 본다.

## 7개 확인

1. **시각 위계**: 히어로는 통과, 카드는 상태보다 장르 banner가 강해 조건부.
2. **간격과 정렬**: 4px 계열과 큰 여백이 일관적.
3. **타이포그래피**: fallback 때문에 재현성 위험.
4. **색과 대비**: 주요 텍스트 대비 충분, 신호색 의미도 일관적.
5. **반응형**: 가로 넘침 없음. 히어로는 모바일 한 화면 조건 미달.
6. **상호작용**: 링크와 카드 focus-visible 있음, reduced-motion 있음.
7. **콘텐츠 진실성**: 가짜 수치·후기 없음.

## 최종 verdict

**CONDITIONAL PASS** — 모바일 히어로 높이와 카드 banner 우선순위를 고친 뒤 출시 검수 재실행.

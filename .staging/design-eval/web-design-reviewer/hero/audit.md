# 랜딩 히어로 감사

## 대상

- `.staging/design-eval/frontend-design/hero/index.html`
- 화면: 1440x900, 390x844

## 발견

| 심각도 | 문제 | 근거 | 제안 |
|---|---|---|---|
| Major → 수정 완료 | 최초 모바일에서 오른쪽 시각 모형까지 한 화면에 모두 보이지 않았다 | 390x844 재검수 전에 visual을 245px, 제목을 52px로 줄였다 | 수정 후 문서 높이 844px로 한 화면 통과 |
| Minor | `Arial Narrow`는 설치 환경에 따라 Arial로 대체되어 의도한 좁은 제목이 달라진다 | 로컬 폰트 의존 | 번들 폰트 또는 명시적 가변 폰트 파일을 로컬 제공 |
| Minor | 보조 CTA와 주 CTA의 형태가 같아 위계 차이가 색에 의존한다 | 두 링크 모두 같은 테두리·굵기 | 보조 CTA를 밑줄 텍스트로 낮추기 |
| Note | 제품 모형은 Rottie의 파일·터미널·AI 연결을 직접 보여준다 | 실제 문구와 로컬 CSS 아티팩트 | 유지 |

## 판정

통과. 최초 모바일 한 화면 문제는 같은 평가에서 수정했고, 로컬 폰트 재현성은 잔여 위험으로 남는다.

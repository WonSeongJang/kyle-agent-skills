- 사용 문서: `skills/design-artifact/SKILL.md`, `skills/html/SKILL.md`, `skills/html-wireframe/SKILL.md`, `skills/html-prototype/SKILL.md`, `skills/html-plan/SKILL.md`, `skills/html-diagram/SKILL.md`
- 적용: 실제 문구, 단일 파일, 의미 있는 HTML, 키보드 포커스, 좁은 화면 재배치, 외부 의존성 없음.
- 랜딩은 주제의 작업 흐름을 오른쪽 터미널 아티팩트로 보여주고, 관제 카드는 기존 토큰과 정보 우선순위를 그대로 보존했다.
- 주특기 파일은 여섯 스킬의 역할을 한 화면에 분리해 라우팅 묶음의 장점을 시험했다.
- 제외: 공개 배포용 `tot` 명령은 사용자 동의가 없어 실행하지 않았다.

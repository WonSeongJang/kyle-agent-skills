# Threads 트렌드 체크

## Why

kyle의 글감 시스템은 두 입구가 필요하다: "내가 한 일"(→ /briefing)과 **"세상이 떠드는 일"(→ 이 스킬)**. 트렌드 글은 도달이 다르지만 수명이 24~48시간이라, 아침에 빠르게 훑고 그날 안에 써야 한다.

## 도구

`~/Dev/contents-core-kyle-thread`의 CLI를 쓴다 (웹 UI 안 띄워도 됨).

```bash
cd ~/Dev/contents-core-kyle-thread
uv run threads-research collect "키워드" --max 30 --sort recent --ensure
```

- `--sort recent` = 최신순 (트렌드 감지용 기본). `--sort top` = 인기순 (검증된 반응 확인용).
- `--ensure` = 토큰 캡처가 없거나 7일 이상 오래되면 자동 재캡처(probe). **로그인은 자동 안 됨** — 세션이 죽어 있으면 `uv run threads-research login`을 kyle에게 요청한다 (실제 브라우저 로그인 1회 필요).
- 결과는 CSV 한 파일로 떨어지며 경로가 명령 출력에 찍힌다. 그 CSV를 읽어 분석한다.

## 절차

1. **키워드 확정**
   - 고정 키워드: `AI`, `사이드프로젝트`, `자동화` (개인 브랜딩 `_project.md` 기준)
   - 그날 이슈어: kyle이 말해준 게 있으면 추가 (예: "어제 ERP 시끌"→ `ERP`). 없으면 고정 키워드만 돌리고, 출력에 "이슈어를 주면 그것도 훑는다"고 한 줄 남긴다.
   - 키워드는 회당 2~4개로 제한 (수집이 계정 세션을 쓰는 작업이라 과하게 돌리지 않는다).
2. **수집** — 키워드마다 `collect ... --max 30 --sort recent --ensure` 실행. 실패하면 에러 원문을 보여주고 멈춘다 (재시도 남발 금지 — 세션 문제일 가능성이 크다).
3. **CSV 분석** — 키워드별로:
   - **작성일(`taken_at`) 필터 먼저.** 인기순(top)은 몇 달~몇 년 전 누적 인기글이 섞이고, 최신순(recent)도 트렌드 보장이 아니다 (2026-07-16 실측: 'AI' top 100 중 49개가 30일+, 1등은 17개월 전 글). 트렌드 판정은 **최근 7일 이내 글만** 걸러서 좋아요 재정렬한 뒤 한다.
   - 최근 7일 글 기준 좋아요 상위 5개의 주제·훅 한 줄씩 (작성일 병기)
   - 반복해서 등장하는 주제 = "지금 시끌한 것" 판정 (근거: 등장 횟수·좋아요 합)
   - 누적 인기글(오래 살아남은 글)은 "장수 콘텐츠 패턴" 참고용으로만 구분해 언급한다.
4. **글감 제안 (최대 3개)** — 각 글감은 반드시 **트렌드가 입구, kyle 이야기가 본문** 구조로 꺾는다:
   - ❌ "ERP 난리네요" (이슈 중계)
   - ✅ "ERP 사태 보면서 든 생각 — 나는 내 작업 시스템을 이렇게 만들었다" (관통선 연결)
   - 비율 원칙 리마인드: 내 이야기 7 : 트렌드 3. 트렌드 글감은 보조다.
5. **저장** — 기본은 대화 출력만. kyle이 "저장해줘"라고 하면:
   - 개인 계정용 글감 → `~/Dev/kyle-hub/research/branding/threads-posts/`에 draft로
   - 회사(모두의인증) 소재가 섞여 있으면 소유권 분리 원칙대로 회사 몫은 `securenet-hub/marketing/`에

## 출력 형식

```markdown
# Threads 트렌드 체크 (YYYY-MM-DD 오전/오후)

## 지금 시끌한 것
(키워드별 2~3줄. 근거 수치 포함 — "○○ 주제 글 4건, 좋아요 합 N")

## 글감 후보 (트렌드 → 관통선으로 꺾기)
1. [입구: 트렌드] → [본문: kyle 이야기] — 왜 지금인지 한 줄
...

## 참고
- 수집 조건 (키워드, 정렬, 글 수) + CSV 경로
```

## 스타일·주의

- 트렌드 판정에는 항상 근거 수치를 붙인다 ("시끌하다"만 말하지 않기).
- 수집 데이터는 그날 스냅샷일 뿐 — "지금 이 순간의 전수 조사"처럼 말하지 않는다.
- 이 스킬은 **감지·글감 제안까지만.** 본문 작성은 5가지 훅 문서(`kyle-hub/research/branding/2026-06-29_threads-인기글-패턴-분석툴-5원칙.md`)를 기준으로 별도 진행.

# Decision Matrix

## Goal

Choose the smallest tracking system that still answers the user's real question.

## Options

### A. Search Console only

Use when the user mainly cares about:

- Google search inflow
- queries
- impressions
- clicks
- CTR
- indexing
- sitemap submission

Do not add an internal dashboard yet unless the user also needs behavior tracking.

### B. Search Console + internal dashboard

Use when the user also cares about:

- which landing pages actually lead to use
- which tools or pages are opened
- which actions complete successfully
- which results are copied or shared

Recommended for utility sites, tool collections, content tools, and lightweight SaaS landing flows.

### C. Search Console + internal dashboard + UTM + short links

Use when the user wants to compare:

- KakaoTalk shares
- blog links
- X/social links
- community/referral links
- default direct shares

This is the right choice when channel attribution matters beyond Google search.

## Dashboard Guidance

Add a dashboard when at least one is true:

- the user wants to measure post-landing behavior
- the user wants non-Google attribution
- the user will share links manually across channels
- the user wants to compare tools or landing pages against each other

Keep the dashboard small at first.

Minimum cards:

- total sessions
- landing sessions
- tool runs
- success rate
- copy rate
- traffic breakdown

## GA vs internal dashboard

Search Console and GA are not the same.

- Search Console = Google search inflow
- GA = site behavior after entry
- internal dashboard = self-hosted behavior and attribution layer

Use an internal dashboard when the user prefers owning the data shape and wants lightweight custom views.

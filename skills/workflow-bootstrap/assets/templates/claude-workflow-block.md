## 공통 운영 규칙

- 모든 작업은 Why를 먼저 확인한다.
- 모든 작업 전후에는 영향분석을 수행한다.
- 구현과 문서화는 함께 진행한다.
- worktree 기반 분산 작업을 우선한다.
- daily 로그를 남긴다.
- 변경 후에는 사용자 흐름 기준으로 다시 확인한다.
- 여러 에이전트가 함께 작업할 때는 역할을 분리한다.

## workflow 기본 원칙

- 조사 -> 구현 -> 리뷰 -> 머지 순서를 유지한다.
- 설정이 없으면 코어 기본값으로 동작한다.
- 프로젝트 차이가 있으면 최소 override 만 둔다.
- 프로젝트 전용 규칙은 이 블록 아래의 별도 섹션으로 분리한다.

# `CLAUDE.md` 일반화 가이드

## 목표

다른 프로젝트에도 가져갈 수 있는 공통 운영 규칙과,
현재 프로젝트에만 남겨야 하는 전용 규칙을 분리한다.

## 공통 운영 규칙 후보

- Why 먼저 쓰기
- 모든 작업 전후 영향분석
- 구현과 문서화 함께 진행
- worktree 기반 분산 작업
- daily 로그 기록
- 변경 후 사용자 흐름 기준 재점검
- 여러 에이전트 역할 분리

## 프로젝트 전용 규칙 후보

- 도메인 설명
- 라우트 구조
- 데이터 모델 설명
- 제품 용어
- 프로젝트만의 디자인 기준
- 프로젝트만의 배포 방식

## 병합 방식

추천 순서:

1. 기존 `CLAUDE.md`를 읽는다.
2. 공통 운영 규칙 문단만 추출한다.
3. `assets/templates/claude-workflow-block.md`와 비교한다.
4. 중복은 제거하고 부족한 내용만 병합한다.
5. 프로젝트 전용 규칙은 원래 위치에 남긴다.

## 피해야 할 것

- `CLAUDE.md` 전체를 템플릿으로 덮어쓰기
- 프로젝트 전용 도메인 설명까지 공통 규칙으로 올리기
- 같은 규칙을 표현만 바꿔 두 번 넣기

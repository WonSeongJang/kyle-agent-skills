# Decision Matrix

## Goal

Decide whether the project needs:

- Search Console only
- Search Console plus internal behavior dashboard
- Search Console plus full operations dashboard

## Levels

### A. Search Console only

Use when:

- Google search inflow is the only question
- the service is very early
- no real internal ops workflow exists yet

### B. Search Console + internal behavior dashboard

Use when:

- landing-to-usage conversion matters
- drop-off points matter
- failure stages matter
- non-Google attribution matters

### C. Search Console + operations dashboard

Use when:

- the team manually handles refunds, holds, restores, or exceptions
- credits, quotas, subscriptions, or risk states need ops visibility
- admin actions need logging

## Rule of thumb

Start from the smallest level that answers the real operating question.

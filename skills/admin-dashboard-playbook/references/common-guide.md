# Common Guide

## Common dashboard core

Typical admin dashboards need to answer:

- Where did users come from?
- Where do they drop off?
- Why did they fail?
- Do operators need to intervene?

## Common sections

- Overview
- Funnel
- Revenue
- Economy
- Risk & Ops
- Exports

## Minimum operating cutline

The dashboard is minimally useful when:

1. failures are grouped by stage and reason
2. traffic can be compared by `source / medium / campaign`
3. a core conversion metric is visible as a card

## Service-type substitution

- Commerce: purchase, refund, chargeback
- Subscription: activation, paid conversion, renewal, cancel
- Content/AI tool: generation success, save, share, quota

# WF-2. 페이크 도어 수요 검증 (만들기 전에 팔아보기)

언제: WF-1 설계가 끝났고, 제작에 며칠 이상 쓸 예정일 때.
강의 원문: "만들고 판매 ㄴㄴ, 수요 보고 판매."

입력: WF-1 산출물 + 랜딩 1장.
산출물: Go / Pivot / Drop 판정 + 근거 수치.

## 절차

1. 랜딩 1장 제작: WF-4로 첫 문구를 쓰고, 신청 버튼 하나만 둔다. 결제 버튼이어도 되고 웨이트리스트 등록이어도 된다.
2. 소액 광고 A/B 테스트: 1~2만원 단위로 집행 (강의: "만원씩 태워보기"). 변수는 한 번에 하나(첫 문구 또는 오퍼). 예산 안전선은 SKILL.md 절대 규칙 4를 따른다.
3. 판정 기준 (초기값, 자기 데이터가 쌓이면 자기 수치로 교체):
   - 랜딩 전환율 6.6% 미만: 후킹/오퍼를 바꿔 재테스트. 평균 이하는 메시지 문제.
   - 6.6~21%: 방향 맞음. 문구 개선 후 제작 착수 가능.
   - 21% 이상 (웨이트리스트 중앙값): 강한 수요 신호. 바로 제작.
   - 광고 클릭 자체가 안 나옴: 타깃/채널 문제. 메시지가 아니라 "누구에게 보여주는가"를 다시.
4. 신청자에게는 진짜 연락: 페이크 테스트로 모은 연락처는 출시 시 첫 고객 후보다. 버리지 않는다.

## 판정 출력 형식

```text
집행 금액: ...
노출/클릭/신청: ...
전환율: ...
판정: Go | Pivot | Drop
근거: ...
다음 행동: ...
```

## 주의

- 업종·단가에 따라 기준 수치는 달라진다. 수치는 방향성 참고용이다.
- 실제 결제 버튼을 공개하는 페이크 도어는 "품절/준비 중" 처리 등 고객 경험 보호 장치를 둔다. 실제 청구는 kyle 승인 전 금지.

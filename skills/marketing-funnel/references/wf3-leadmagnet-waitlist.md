# WF-3. 리드마그넷 -> 연락처 수집 -> 웨이트리스트 -> 출시 전환

언제: WF-2에서 수요가 확인됐거나, 출시 전 명단을 미리 모으고 싶을 때.

입력: WF-1 설계도.
산출물: 리드마그넷 1개 + 수집 장치 + 예약 발송 시퀀스.

## 절차

1. 리드마그넷 선택: 체크리스트, 템플릿, 미니강의, 묻기 툴, 퀴즈 중에서 "만드는 데 1일 이하 + 타깃 문제와 직결"인 것을 고른다.
2. 도파민 > 귀찮음 점검: 받는 사람 입장에서 "얻는 것의 기쁨"이 "입력의 귀찮음"을 넘는지 시뮬레이션한다. 입력 칸은 1개(이메일 또는 번호)부터 시작한다.
3. 묻오 콘텐츠 품질 게이트: 공짜로 준 것만으로 "실망이 아니라 만족"인지 확인한다.
   - 강의 원문: "묻오콘텐츠로도 실망을 안 하고 만족하게 만들어야 한다."
   - 여기서 실망하면 다음 단계 전환은 죽는다.
4. 수집 -> 웨이트리스트 연결: 신청 즉시 환영 메시지 + "다음에 올 것"을 예고한다.
   - 참고 벤치마크: 웨이트리스트 전환 중앙값 약 21%, 추천(레퍼럴) 유입 시 약 3.1배. 친구 추천 장치를 붙일지 여기서 결정한다.
5. 출시 전환 시퀀스: 출시일에 명단에 먼저 판다. 웨이트리스트 -> 구매 전환이 퍼널의 첫 매출이다.

## 도구 후보

- 랜딩/폼: Carrd, Framer, Typeform, Tally
- 이메일/명단: Kit(구 ConvertKit), Beehiiv
- 한국 맥락: 카카오 채널(번호 수집 대체), 스티비(이메일)
- 선택 기준과 상세는 research-map.md의 리드마그넷 문서 참조.

## 법적 안전

- 수집한 연락처는 명시한 용도(출시 안내 등)로만 쓴다.
- 명단 기반 발송은 수집 시 안내/동의 문구를 둔다. 콜드(비동의) 연락처 매입/스크래핑 발송은 하지 않는다.
